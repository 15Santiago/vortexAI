# vortexAI

> Panel de análisis de productos de comercio electrónico, con catálogo, métricas y administración de cuentas.

vortexAI reúne información de productos en un catálogo consultable y presenta indicadores como precios, valoraciones, reseñas y categorías. Incluye recomendaciones personalizadas, autenticación de usuarios, permisos administrativos y registros de auditoría.

## Reglas de desarrollo

1. Los paquetes de JavaScript se instalarán obligatoriamente mediante `pnpm`.
2. El backend se desarrollará con FastAPI utilizando Python, y sus dependencias se instalarán mediante `pip`.
3. La base de datos será MySQL.
